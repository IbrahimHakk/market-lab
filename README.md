# Market Lab

Public landing page for **Market Lab**, a personal e-commerce research and Etsy listing workflow currently under development.

This repository contains only the public informational website used to describe the application. The private application source code, API credentials, access tokens, and other secrets are not stored here.

## Publish with GitHub Pages

1. Open this repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select **main** and **/(root)**, then save.
5. GitHub will publish the site at the Pages URL shown in that settings screen.

## Scope

Market Lab is intended to research product opportunities using permitted marketplace and trend data, keep source availability visible, and assist the account owner with listing preparation. Planned Etsy functionality uses the official Etsy API, and publishing or editing actions require explicit user approval.
